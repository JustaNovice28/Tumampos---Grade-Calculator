When I first initialized my repository, I encountered a confusing hurdle where I completely failed to create a secondary branch. Every time I ran git branch feature-branch or tried to inspect my work using git branch -a, the terminal returned absolutely nothing, and no branches were generated. I felt stuck because I could not figure out why the basic branching commands were completely failing to respond in my local environment.
After looking up the issue, I discovered that Git is snapshot-based and requires a foundation to branch from. Because my project folder was completely brand new and empty, Git did not have a main or master branch fully realized yet. To fix this obstacle, I created my baseline files, ran git add ., and executed my very first commit using git commit -m "Initial commit". Once that first commit established a historical baseline on the default branch, the branching engine woke up. I was immediately able to successfully run git checkout -b feature-branch to create and switch to my secondary branch without any further issues.
