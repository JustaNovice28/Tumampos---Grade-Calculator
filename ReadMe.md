Description
This is a lightweight command-line Python application that calculates a student's final grade using weighted scores: 30% from quizzes, 50% from major exams, and 20% from assignments. It translates the numerical final average into a traditional letter grade (A-F).

How to Run this Program
1. Ensure you have Python 3 installed on your machine.
2. Open your terminal or command prompt.
3. Navigate to the repository folder.
4. Run the program using the following command:
   ```bash
   python calculator.py
   ```
